# 权限边界

业务 API 使用 `Authorization: Bearer <JWT>`，身份和管理员角色由数据库实时读取。
试卷、题目、插图、错题的访问按当前用户归属校验，越权返回 404。
登录 JWT 必须包含 `sub` 和 `exp`。

| 模型来源 | 用户查看/启用/测试 | 用户编辑/删除 | 管理员编辑/删除/测试 |
| --- | --- | --- | --- |
| 用户自建 | 仅本人 | 仅本人 | 禁止 |
| 后台分配 | 仅分配对象 | 禁止 | 允许 |
| 系统模型 | 公共开关开启时 | 禁止 | 允许 |

用户模型没有 API key 时不能回退使用服务器环境变量密钥。
仅服务器默认识别 Provider 明确允许读取环境变量密钥。
模型 API 响应只返回密钥是否存在，不返回密钥值。

`/files` 不再匿名提供静态文件。已鉴权 API 返回绑定路径、访问人、用途的
15 分钟签名链接；下载时再次检查用户存在、资源归属或管理员角色。
数据库和非图片文件不在可访问范围。签名使用与登录 JWT 分离的派生密钥。
签名链接失效后，客户端需重新请求业务详情获取新链接。

动态插图 `GET /api/v1/illustrations/{id}/image` 使用题目响应中
`illustrations[].imageUrl` 的 15 分钟签名，绑定插图 ID 和访问人。
下载时重新检查资源归属，也支持请求头鉴权。所有接口均不接受 URL 登录 token。
网页、移动端和小程序直接使用此签名 URL；新后端需要与客户端更新一同发布。
