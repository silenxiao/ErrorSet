# 权限边界

业务 API 使用 `Authorization: Bearer <JWT>`，身份和管理员角色由数据库实时读取。
试卷、题目、插图、错题的访问按当前用户归属校验，越权返回 404。
登录 JWT 必须包含 `sub`、`identity` 和 `exp`。`identity` 与账号独立随机身份匹配，
数字 ID 复用也不能继承旧登录态。升级后旧格式令牌需重新登录。
SQLite 用户/题目表使用 `AUTOINCREMENT`；启动迁移保留数据、索引与触发器，
序列跨过历史记录引用的已删除 ID。错题覆盖及唯一索引冲突分支都检查归属与覆盖授权。

登录/注册限流默认忽略转发头；仅当实际连接地址属于 `TRUSTED_PROXY_CIDRS` 时，
从右向左回溯转发链，停在第一个非可信地址。后端以 `--no-proxy-headers` 启动，
避免 Uvicorn 提前重写地址。部署入口 nginx 覆盖客户端提供的 `X-Forwarded-For`。
代理列表应仅包含真实代理地址；未配置时同一代理的用户共享限流额度，详见 DEPLOY.md。

新设密码（注册、修改、管理员重置）统一要求至少 6 个字符，UTF-8 编码后不超过
72 字节；超限返回 422，不截断密码。登录验证保持原有 bcrypt 哈希格式。
修改/重置密码会与密码哈希在同一事务轮换账号登录身份，撤销所有旧登录 JWT。
首次启动仅在用户表为空时播种管理员；已有账号不会因库内无管理员而在重启时自动提权。

| 模型来源 | 用户查看/启用/测试 | 用户编辑/删除 | 管理员编辑/删除/测试 |
| --- | --- | --- | --- |
| 用户自建 | 仅本人 | 仅本人 | 禁止 |
| 后台分配 | 仅分配对象 | 禁止 | 允许 |
| 系统模型 | 公共开关开启时 | 禁止 | 允许 |

用户模型没有 API key 时不能回退使用服务器环境变量密钥。
仅服务器默认识别 Provider 明确允许读取环境变量密钥。
模型 API 响应只返回密钥是否存在，不返回密钥值。

模型出站请求只允许 HTTPS 443 公网端点。保存配置和构建 Provider 时检查 URL；
实际连接时解析并校验所有 DNS 答案，拒绝非公网或混合公网/内网结果，
然后只连接已通过校验的数字 IP，保留原始 Host 和 TLS SNI/证书校验。
连接池仍按原始域名隔离。流式调用和普通调用共用该防护。
请求不跟随重定向，也不读取环境变量代理；旧内网模型配置会被拒绝调用。
DNS 解析和公网 IP 尝试共用连接超时预算。

HTTPX 传输适配器使用其 0.28 系列的 `_pool` 集成点，版本限制为
`httpx>=0.28,<0.29`、`httpcore>=1.0,<2`。升级时须重新验证 TLS、流式和建连测试。
参考 [HTTPX transport 接口](https://www.python-httpx.org/advanced/transports/) 和
[HTTPCore 连接池](https://www.encode.io/httpcore/connection-pools/)。

`/files` 不再匿名提供静态文件。已鉴权 API 返回绑定路径、访问人、用途的
15 分钟签名链接；下载时再次检查用户存在、资源归属或管理员角色。
数据库和非图片文件不在可访问范围。签名使用与登录 JWT 分离的派生密钥。
签名链接失效后，客户端需重新请求业务详情获取新链接。

动态插图 `GET /api/v1/illustrations/{id}/image` 使用题目响应中
`illustrations[].imageUrl` 的 15 分钟签名，绑定插图 ID 和访问人。
下载时重新检查资源归属，也支持请求头鉴权。所有接口均不接受 URL 登录 token。
网页、移动端和小程序直接使用此签名 URL；新后端需要与客户端更新一同发布。
