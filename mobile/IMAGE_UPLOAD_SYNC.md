# 本次聊天的小程序改动与 mobile 同步清单

| 功能 | mobile 实现 |
| --- | --- |
| 应用内裁剪 | 拖动蓝色框体移动位置；八向手柄调整范围，限制在图片边界内 |
| 旋转与恢复 | 每次旋转 90°；恢复最初选中的图片，清除旋转与裁剪；重新编辑保留原图 |
| 确认后上传 | 选图后先打开编辑器，确认才更新上传对象；取消保留之前确认的图片 |
| 底部按钮 | 统一 44px 高度；取消灰底、编辑操作浅蓝底、确认蓝底，包含忙碌状态 |
| 尺寸规则 | 上传预览、编辑、打开试卷与原图弹窗：小图保持原始像素尺寸，超出可用宽高等比缩小；插图大图预览已有相同规则 |
| 默认命名 | 相册返回真实文件名时使用完整文件名；拍照或无文件名时使用设备当前日期时间 `YYYY-MM-DD HH:mm:ss`；手动命名保留，换图更新自动名称 |
| 格式与大小 | 确认时明确导出 JPEG；上传文件名 `.jpg` 与 MIME `image/jpeg` 匹配；确认后检查 10MB 限制 |
| 题目渲染 | 分子分母分别保持一行，嵌套分式逐级缩小，支持 `\cdots`，保留空行后小题编号 |

mobile 不使用微信的“从聊天选择图片”入口；相册通过 ImagePicker 提供文件名。

新增 SDK 57 兼容依赖 `expo-image-manipulator`、`expo-file-system`。未自动打包 APK；现有自定义开发客户端需要包含新增原生模块。

6 项回归测试、TypeScript 检查和修改文件的 lint 通过。全项目 lint 仍有原有 `ui.tsx` 渲染期间读取 ref 的错误，以及 `models.tsx` 未使用导入的警告。触摸交互与实际导出仍需 Android/iOS 真机验证。
